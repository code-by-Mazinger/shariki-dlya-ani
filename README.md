# Шарики для Ани

Спокойная головоломка-сортировка: разложи шарики по пробиркам, чтобы в каждой был один цвет. У каждого цвета своя нота, собранная пробирка звучит аккордом, пройденный уровень — мелодией. Каждые 3 уровня открывают картину для галереи: 10 шедевров живописи, 30 уровней, дальше — свободная игра.

- Без таймеров, рекламы и проигрыша; отмена хода без ограничений.
- Работает в браузере телефона; на iPhone: Safari → «Поделиться» → «На экран Домой» — откроется как приложение, работает и без интернета.
- Проверка логики: `node selfcheck.js` (все уровни решаемы и одинаковы при каждом запуске).
- Картины — общественное достояние, источники: `img/CREDITS.md`.
