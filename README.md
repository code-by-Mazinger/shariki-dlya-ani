# Шарики для Ани

Спокойная головоломка-сортировка: разложи шарики по пробиркам, чтобы в каждой был один цвет. У каждого цвета своя нота, собранная пробирка звучит аккордом, пройденный уровень — мелодией. Котик-путешественник идёт по карте городов из еды: «Ягодная деревня» (уровни 1–50, с 31-го — смешение цветов) и «Сырный городок» (51–100, часть шариков спрятана под сырной корочкой). За каждые 5 уровней на карте вырастает домик из еды. За уровни 1–45 открываются 15 блюд кулинарной книги Ани — с секретом повара и рецептом. Дальше — свободная игра. Домики — `houses.js`.

- Без таймеров, рекламы и проигрыша; отмена хода без ограничений.
- Работает в браузере телефона; на iPhone: Safari → «Поделиться» → «На экран Домой» — откроется как приложение, работает и без интернета.
- Проверка логики: `node selfcheck.js` (все уровни решаемы и одинаковы при каждом запуске).
- Картинки блюд — источники и оговорки: `img/CREDITS.md`.
